# FlightStatus

Die Flugbarkeits-Pille: Fliegbar, Grenzwertig oder Nicht fliegbar – immer mit Wort, Icon und Farbe zugleich.

**Der Consumer liefert:** `status` (`go` | `caution` | `stop`), optional `label` für präzisere Wörter («Föhn-Tendenz», «Gültig», «Offen»).

- Nie Farbe allein: Häkchen, Ausrufezeichen und Kreuz unterscheiden auch bei Farbsehschwäche.
- Die Einstufung ist eine **Orientierung**, keine Freigabe. Auf jeder Seite mit Status steht der Satz: «Die Entscheidung zu starten liegt immer bei dir als Pilot/in.»
- Wiederverwendet für andere Zustände mit derselben Logik (Jahreskarte gültig/offen/ungültig).
